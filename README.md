# Dotfiles


The Dotfiles are managed with [stow](https://www.gnu.org/software/stow).

All Dotfiles are relative to the home directory (/home/user/).


Dotfiles for the following applications are managed:
- [kitty](https://sw.kovidgoyal.net/kitty/)
- [neovim](https://github.com/neovim/neovim)
- [zsh / ohmyzsh](https://github.com/ohmyzsh/ohmyzsh)



### Notes for applications

#### zsh
> ZSH is built ontop of the default CachyOS zsh configuration

Additional applications for zsh:
- [zoxide](https://github.com/ajeetdsouza/zoxide)
- [powerlevel10k](https://github.com/romkatv/powerlevel10k)
